# 🚚 Telegram бот для формування заявок на перевезення

Бот для автоматизації створення та обліку заявок на перевезення вантажу з функціями збереження шаблонів, експорту в Google Sheets та інтеграцією з API Нової Пошти.

## 🎯 Можливості

### Створення заявок
- ✅ **Нова заявка** - повна форма з усіма полями
- ✅ **⚡ Швидка заявка** - скорочена форма для термінових запитів (пропускає примітки, склади, контакти)
- ✅ **Форма для заявок** - зручне заповнення інформації про перевезення
- ✅ **Прогрес** - індикатор виконання форми (X/Y)

### Керування заявками
- ✅ **📋 Мої заявки** - перегляд усіх створених заявок користувача
- ✅ **ID заявок** - головний ID заявки + дочірні ID для split-рядків (наприклад: A1B2C3D4-01)
- ✅ **Редагування заявок** - можливість змінити дані вже відправленої заявки
- ✅ **Видалення заявок** - позначення заявки як "ВИДАЛЕНО" в Google Sheets
- ✅ **Копіювання заявок** - створення нової заявки на основі існуючої
- ✅ **Відновлення заявок** - повернення видаленої заявки до статусу "АКТИВНА"
- ✅ **Мульти-НП** - додавання кількох населених пунктів завантаження/розвантаження
- ✅ **Розподіл обсягу** - при кількох НП розвантаження бот запитує обсяг для кожного НП

### Шаблони і автозаповнення
- ✅ **Шаблони** - збереження та швидке завантаження попередніх заявок
- ✅ **Завантаження шаблонів** - вибір зі збережених форм
- ✅ **Видалення шаблонів** - очищення застарілих шаблонів
- ✅ **Автозаповнення контактів** - збереження контактів для швидкого вибору

### Інтеграції
- ✅ **Календар** - вибір дати або періоду перевезення з інтерактивного календаря
- ✅ **Пошук міст** - інтеграція з API Нової Пошти для пошуку населених пунктів
- ✅ **Google Sheets** - автоматичний експорт заявок в таблицю
- ✅ **PostgreSQL** - зберігання заявок, шаблонів та контактів у хмарній БД

### Валідація і логіка
- ✅ **Умовна логіка** - автоматичне пропускання полів на основі типу вантажу
- ✅ **Валідація** - перевірка введених даних (числа для обсягу, формати контактів)
- ✅ **Локалізація** - повна підтримка української мови
- ✅ **Split-експорт** - одна заявка в чаті, кілька рядків у Google Sheets за НП розвантаження

## 📋 Спеціальна обробка типів вантажу

- **КАС, РКД, АМ вода** (рідкі наливні) - автоматичне пропускання полів способу завантаження/розвантаження
- **Насип** - автоматичне встановлення способу розвантаження на "Самоскид"
- **Біг-бег** - додаткове запитання про вагу 1 біг-бегу (у кілограмах)
- **Швидка заявка** - автоматично пропускає: склади, способи завантаження/розвантаження, контакти, примітки

## 🚀 Локальне встановлення

1. **Клонуйте репозиторій**

2. **Створіть віртуальне середовище:**
```bash
python -m venv .venv
.venv\Scripts\activate  # На Windows
source .venv/bin/activate  # На Linux/Mac
```

3. **Встановіть залежності:**
```bash
pip install -r requirements.txt
```

4. **Налаштуйте змінні середовища (.env):**
```bash
# Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here
TARGET_CHAT_ID=your_group_chat_id
BOT_USERNAME=your_bot_username

# Admin (опційно - для сповіщень про помилки)
ADMIN_USER_ID=your_telegram_user_id

# PostgreSQL
DATABASE_URL=postgresql://user:password@host:port/database

# Nova Poshta API
NOVAPOSHTA_API_KEY=your_api_key_here

# Google Sheets (опційно - для експорту)
GOOGLE_CREDENTIALS_FILE=google-credentials.json
GOOGLE_SPREADSHEET_ID=your_spreadsheet_id
GOOGLE_WORKSHEET_NAME=ЗАЯВКА
```

5. **Запустіть бота:**
```bash
python bot.py
```

## 🗄️ База даних

**PostgreSQL** на Railway для зберігання:
- **Таблиця requests** - усі заявки користувачів з ID, статусом, даними (JSONB формат)
- **Таблиця templates** - збережені шаблони заявок (JSONB формат)
- **Таблиця contacts** - історія контактів користувачів для автозаповнення

Таблиці автоматично створюються при першому запуску. Всі дані в хмарі, синхронізовані 24/7.
Для міграцій використовується автоматична перевірка типів полів (приклад: INTEGER → BIGINT для user_id).

## 🔄 Робочий процес

### 1. Початок роботи
Користувач запускає `/start` та бачить головне меню:
- **📝 Нова заявка** - повна форма з усіма полями
- **⚡ Швидка заявка** - скорочена форма для термінових запитів
- **📋 Мої заявки** - перегляд та керування створеними заявками
- **📂 Завантажити шаблон** - вибір зі збережених форм
- **🗑️ Видалити шаблон** - видалення застарілих шаблонів

### 2. Заповнення форми
- Покрокове заповнення всіх необхідних полів
- Вибір з варіантів або введення власних даних
- Автоматичне пропускання полів (залежно від типу вантажу)
- Пошук населених пунктів через Nova Poshta API
- Для НП завантаження/розвантаження можна додати кілька пунктів (додавання/видалення останнього)
- Для кількох НП розвантаження виконується розподіл загального обсягу по пунктах
- Вибір дати/періоду через календар
- Індикатор прогресу (X/Y)

### 3. Підтвердження
- Перевірка введених даних
- Можливість редагування окремих полів
- Для швидкої заявки: "Додати деталі" або "Надіслати"

### 4. Відправка
- Заявка надсилається в груповий чат одним повідомленням
- Отримання головного ID заявки (8 символів)
- Автоматичний експорт у Google Sheets (для кількох НП розвантаження - окремі рядки з дочірніми ID)
- Збереження в БД PostgreSQL

### 5. Меню після відправки
- **✏️ Редагувати заявку** - змінити дані вже відправленої заявки
- **🗑️ Видалити заявку** - позначити як "ВИДАЛЕНО"
- **💾 Зберегти як шаблон** - зберегти для повторного використання
- **✅ Готово** - завершити роботу

### 6. Команди
- `/start` - почати роботу з ботом
- `/cancel` - скасувати поточну операцію
- `/my_requests` - переглянути свої заявки
- `/edit_request <ID>` - редагувати заявку за ID
- `/delete_request <ID>` - видалити заявку за ID
- `/restore_request <ID>` - відновити видалену заявку
- `/request` - створити кнопку для заявок у групі (тільки в групах)

## 🔑 Налаштування інтеграцій

### Telegram Bot
1. Створіть бота через [@BotFather](https://t.me/BotFather)
2. Отримайте токен (TELEGRAM_BOT_TOKEN)
3. Додайте бота в групу та отримайте ID групи (TARGET_CHAT_ID)

### Nova Poshta API
1. Зареєструйтесь на [novaposhta.ua](https://novaposhta.ua)
2. Особистий кабінет → Налаштування → Безпека → API ключі
3. Скопіюйте ключ (NOVAPOSHTA_API_KEY)

### Google Sheets API
1. Створіть проект в [Google Cloud Console](https://console.cloud.google.com)
2. Увімкніть Google Sheets API та Google Drive API
3. Створіть Service Account та завантажте JSON ключ
4. Надайте доступ Service Account email до вашої таблиці (Editor)
5. ID таблиці візьміть з URL: `docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit`

## ⚙️ Особливості реалізації

### ID заявок
- Головний ID заявки: 8-символьний UUID (приклад: `A1B2C3D4`)
- Для split-рядків у таблиці генеруються дочірні ID (приклад: `A1B2C3D4-01`, `A1B2C3D4-02`)
- У чат надсилається одна загальна заявка з головним ID
- У Google Sheets кілька НП розвантаження експортуються окремими рядками з дочірніми ID

### Фільтр логування
- Автоматичне маскування токенів Telegram у логах
- Приховування DATABASE_URL та Google credentials
- Безпечне логування без витоку чутливих даних

### Часова зона
- Використовується часова зона `Europe/Kyiv` (UTC+2/+3)
- Всі дати та час відображаються в київському часі

### Видалення повідомлень
- Автоматичне видалення повідомлень користувача для чистоти чату
- Видалення попередніх питань бота при переході далі
- Спеціальна обробка для об'єднання "Біг-бег" + вага

### Валідація даних
- Перевірка чисел для обсягу/ваги
- Нормалізація номерів телефонів (формат: `050-123-45-67`)
- Парсинг контактів на ПІБ та телефон

### Умовна логіка
- Автоматичне пропускання непотрібних полів залежно від типу вантажу
- Швидка заявка пропускає деталі (склади, контакти, примітки)
- Біг-бег запитує додаткову вагу одного мішка
- Якщо вказано кілька НП розвантаження, поле "Склад розвантаження" пропускається

## ❓ FAQ та Troubleshooting

### Бот не відповідає в групі
- Переконайтеся, що `TARGET_CHAT_ID` правильний (використовуйте [@getidsbot](https://t.me/getidsbot))
- Перевірте, що бот доданий до групи як адміністратор
- Команда `/request` працює тільки в групах

### Помилка "DATABASE_URL not set"
- Додайте PostgreSQL addon в Railway Dashboard
- Змінна `DATABASE_URL` створюється автоматично
- Локально: створіть файл `.env` з правильним підключенням

### Google Sheets не працює
- Перевірте, що Service Account має доступ до таблиці (Editor)
- `GOOGLE_SPREADSHEET_ID` повинен бути з URL таблиці
- На Railway: `GOOGLE_CREDENTIALS_JSON` має бути одним рядком (без переносів)
- Локально: можна використовувати файл JSON, але безпечно тримати ключ у змінній середовища та не зберігати файл у репозиторії

### У таблиці кілька рядків на одну заявку
- Це нормально для заявок з кількома НП розвантаження
- Кожен рядок має дочірній ID заявки (`-01`, `-02`, ...)
- У чаті при цьому залишається одна загальна заявка з головним ID

### Пошук міст не знаходить результатів
- Перевірте `NOVAPOSHTA_API_KEY` в налаштуваннях
- API може бути тимчасово недоступний
- Користувач може ввести назву вручну (кнопка "✍️ Ввести вручну")

### Не приходять сповіщення про помилки
- Додайте `ADMIN_USER_ID` в змінні середовища
- ID можна отримати через [@userinfobot](https://t.me/userinfobot)
- Сповіщення приходять тільки про критичні помилки експорту

### Бот не запускається на Railway
- Перевірте логи в Railway Dashboard
- Переконайтеся, що всі змінні середовища встановлені
- Файл `runtime.txt` має містити версію Python 3.11+
