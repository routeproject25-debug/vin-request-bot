# 🚚 Telegram бот для формування заявок на перевезення

Бот для автоматизації створення та обліку заявок на перевезення вантажу з функціями збереження шаблонів, експорту в Google Sheets та інтеграцією з API Нової Пошти.

## 🎯 Можливості

- ✅ **Форма для заявок** - зручне заповнення інформації про перевезення
- ✅ **Нова заявка** - повна форма з усіма полями
- ✅ **⚡ Швидка заявка** - скорочена форма з основних полів
- ✅ **Шаблони** - збереження та швидке завантаження попередніх заявок
- ✅ **Календар** - вибір дати перевезення з інтерактивного календаря
- ✅ **Пошук міст** - інтеграція з API Нової Пошти для пошуку населених пунктів
- ✅ **Google Sheets** - автоматичний експорт заявок в таблицю
- ✅ **Умовна логіка** - автоматичне пропускання полів на основі типу вантажу
- ✅ **Редагування** - можливість змінити дані перед відправкою
- ✅ **Валідація** - перевірка введених даних (числа для обсягу, формати телефонів)
- ✅ **Локалізація** - повна підтримка української мови
- ✅ **Прогрес** - індикатор виконання форми (X/Y)

## 📋 Спеціальна обробка типів вантажу

- **КАС, РКД, АМ вода** - автоматичне пропускання полів способу завантаження/розвантаження
- **Насип** - автоматичне встановлення способу розвантаження на "Самоскид"
- **Біг-бег** - додаткове питання про вагу 1 біг-бегу

## 🛠️ Технології

- Python 3.11+
- python-telegram-bot 20.7
- PostgreSQL (хмарна БД на Railway)
- Google Sheets API (gspread, google-auth)
- Nova Poshta API (для пошуку населених пунктів)

## 🚀 Локальне встановлення

1. **Клонуйте репозиторій**

2. **Створіть віртуальне середовище:**
```bash
python -m venv .venv
.venv\Scripts\activate  # На Windows
source .venv/bin/activate  # На Linux/Mac
```

3. **Встановіть залежності:**
```bash
pip install -r requirements.txt
```

4. **Налаштуйте змінні середовища (.env):**
```bash
# Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here
TARGET_CHAT_ID=your_group_chat_id
BOT_USERNAME=your_bot_username

# PostgreSQL
DATABASE_URL=postgresql://user:password@host:port/database

# Nova Poshta API
NOVAPOSHTA_API_KEY=your_api_key_here

# Google Sheets (optional - для експорту)
GOOGLE_CREDENTIALS_FILE=google-credentials.json
GOOGLE_SPREADSHEET_ID=your_spreadsheet_id
GOOGLE_WORKSHEET_NAME=ЗАЯВКА
```

5. **Запустіть бота:**
```bash
python bot.py
```

- `.env.example` - приклад конфігурації (без реальних даних)

**PostgreSQL** на Railway для зберігання:

## 🔄 Робочий процес

1. **Початок роботи** - користувач запускає `/start`
2. **Вибір типу заявки:**
   - **📝 Нова заявка** - повна форма з усіма полями
   - **⚡ Швидка заявка** - скорочена форма для термінових запитів
   - **📂 Завантажити шаблон** - вибір зі збережених форм
   - **🗑️ Видалити шаблон** - видалення застарілих шаблонів
3. **Заповнення форми:**
   - Послідовні питання з індикатором прогресу "(X/Y)"
   - Пошук міст через API Нової Пошти
   - Вибір дат через інтерактивний календар
   - Валідація введених даних (числа, формати)
   - Можливість повернутися назад кнопкою "⬅️ Назад"
4. **Підтвердження:**
   - Перегляд заповненої заявки
   - Редагування окремих полів
   - Відправка в групу Telegram
   - Автоматичний експорт в Google Sheets
5. **Збереження шаблону:**
   - Пропозиція зберегти для повторного використання
   - Швидке завантаження при наступних заявках

## 🔑 Налаштування інтеграцій

### Telegram Bot
1. Створіть бота через [@BotFather](https://t.me/BotFather)
2. Отримайте токен (TELEGRAM_BOT_TOKEN)
3. Додайте бота в групу та отримайте ID групи (TARGET_CHAT_ID)

### Nova Poshta API
1. Зареєструйтесь на [novaposhta.ua](https://novaposhta.ua)
2. Особистий кабінет → Налаштування → Безпека → API ключі
3. Скопіюйте ключ (NOVAPOSHTA_API_KEY)

### Google Sheets API
1. Створіть проект в [Google Cloud Console](https://console.cloud.google.com)
2. Увімкніть Google Sheets API та Google Drive API
3. Створіть Service Account та завантажте JSON ключ
4. Надайте доступ Service Account email до вашої таблиці (Editor)
5. ID таблиці візьміть з URL: `docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit`
