# Changelog

## [Функціональне оновлення] - 2026-03-19

### 🚀 Нові можливості в боті
- Додано мультивибір НП завантаження/розвантаження:
	- `➕ Додати ще пункт`
	- `➖ Видалити останній пункт`
	- `✅ Готово`
- Для НП завантаження додано `Пропустити`.
- Додано розподіл обсягу при кількох НП розвантаження:
	- бот запитує кількість на кожен НП,
	- контролює суму розподілу до загального обсягу.
- У режимі редагування НП виправлено UX:
	- перший новий НП замінює старий список,
	- при `⬅️ Назад` відновлюється попереднє значення.

### 📊 Google Sheets
- Реалізовано split-експорт для кількох НП розвантаження:
	- у чаті залишається одне загальне повідомлення,
	- у таблиці створюються окремі рядки по НП.
- Додано дочірні ID рядків (`A1B2C3D4-01`, `A1B2C3D4-02`, ...).
- Команди видалення/відновлення оновлюють усі рядки, пов'язані з головною заявкою.

### 📋 Мої заявки
- У `Мої заявки` split-частини відображаються окремими позиціями з дочірніми ID.
- Дії (редагувати/видалити/копія) коректно працюють і при використанні дочірнього ID.

### 📚 Документація
- Оновлено `README.md` під нову поведінку мульти-НП, split-експорту і дочірніх ID.
- Синхронізовано `RAILWAY_SETUP.md` і `.env.example` з актуальними змінними та сценаріями.
